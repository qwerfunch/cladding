# v0.6.0 real-user verification — install battery · hooks A/B · 3-arm ledger build

> Compressed abstract — 2026-07-05, 0.8.1 cleanup. Original run 2026-06-10~11 against the 0.6.0-candidate develop tarball (post-624825f). Operationally superseded by the 0.7.1 real-usage battery + 0.8.0 surface-fired telemetry; negative results and bug catches preserved below.

**What it was:** the 0.5.2 pattern scaled up — tarball-install the engine like a real user (isolated prefix + HOME), verify everything from the OUTSIDE, then drive real headless Claude Code sessions on external fixtures. No in-repo shortcuts.

**3 shipped-bug catches** (deterministic battery, 31/31 after fix; all fixed in 624825f):
1. `clad sync`'s test_ref repair ate 2 leading path chars under the REAL invocation (cwd='.'), persisted corrupt refs into user shards, and re-fired on its own output every sync — **SHIP BLOCKER** (in-repo tests passed on absolute temp cwds; only the real-user path exposed it). Fix: `path.relative()` + no-op rewrite guard + `process.chdir` regression tests.
2. Bare `npx tsc` on a toolchain-less machine auto-installed and EXECUTED the typosquat package `tsc@2.0.4` (not TypeScript) — **supply chain**. Fix: all gate toolchain invocations use `npx --no-install`; absent tool → honest skip escalated by the strict demand table.
3. `clad serve`'s banner wrote to stdout — the MCP wire — **protocol corruption** for strict JSON-RPC clients. Fix: banner → stderr.

**Conformance NULLs (protected negative results):** vocabulary-adapted, vanilla ties the best cladded arm on every task — event-sourced ledger 10/10, LRU cache 6/6, priority job-queue 8/10, spreadsheet engine 12/12, and cold-newcomer comprehension 8/8 — the 5th–8th conformance NULLs, consistent with every prior A/B (6/9/34/48 features): a capable model does not need cladding to be *correct* on a greenfield task. Governance buys traceability, enforcement, and audit — **not correctness**.

**Oracle-policy design-defect finding:** the voluntary impl-blind-oracle workflow drove a ~5× token premium (~42% of output tokens hooks-ON / ~52% hooks-OFF). Classified a **design defect** — the oracle-policy knob binds the GATE but not the BEHAVIOR, so prose guidance overrode an undeclared (no-mandate) policy and spent the user's tokens on verification the project never opted into. 0.6.1 lever: persona/tool guidance keyed to `clad oracle --required` (the policy's worklist) plus a "not mandated — voluntary" notice on out-of-policy authoring. (Two further release-blocking classes these external runs caught that in-repo suites missed: done-at-creation earn-bypass, fixed ea6c804; and the open npx version-skew flip — the named 0.7 lever.)
