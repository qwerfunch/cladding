# dashboard (vanilla)

This is the **vanilla** group's React + Vite + TS + Tailwind dashboard — auto-generated by
`tests/scenarios/ab-extended/_curator-dashboard.ts` as part of the large-scale A/B
evaluation framework.

No cladding scaffold — just the React app source. Vanilla developer would ship this on its own.

## Run locally

```bash
cd "${this directory}"
npm install
npm run dev    # opens at http://localhost:5173
```

## Test

```bash
npm test
```
