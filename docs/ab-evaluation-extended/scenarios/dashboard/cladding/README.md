# dashboard (cladding)

This is the **cladding** group's React + Vite + TS + Tailwind dashboard — auto-generated by
`tests/scenarios/ab-extended/_curator-dashboard.ts` as part of the large-scale A/B
evaluation framework.

Includes the full cladding governance scaffold: `spec.yaml`, 30 `spec/features/*.yaml` shards, `spec/architecture.yaml`, `spec/capabilities.yaml`, plus `docs/project-context.md` and `docs/conventions.md`.

## Run locally

```bash
cd "${this directory}"
npm install
npm run dev    # opens at http://localhost:5173
```

## Test

```bash
npm test
```
